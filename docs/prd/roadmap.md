# 版本规划

2026-10-04：v0.1.1 已发布，包含 Web 管理与 Android 客户端版本升级；Android 增加服务器关闭注册时的明确提示，不包含用品/保修提醒。维护者确认 v0.1.0 正式发布验收完成；阶段 A 剩余可靠性验收继续延期。设计相关 UI 实施前仍需更新原稿并重新核验连接。

## v0.1.0：已完成正式发布验收

范围与验收要求见 [v0.1.0 需求与边界](v0.1.0.md)。维护者于 2026-10-03 确认正式发布验收完成。

已有实施与测试证据见 [执行记录](../history/roadmap-execution.md)。旧路线图中已经完成的入口修正、统计口径、表单和列表体验工作不再重复排期。

## v0.1.1：Web 平台、管理与 Android 更新

- v0.1.0 正式发布验收已完成；阶段 A 剩余 Android 后台与实体设备可靠性验收延期，不阻塞本版本。
- 新增共享 Android 同步账号数据的响应式 Web 客户端，覆盖资产/用品主要操作；Web 写入经版本化接口进入现有同步事件流，Android 仍以 Room 为本地唯一数据源。
- 新增超管登录及账号状态管理、所有业务数据管理、通用文本配置文件管理、按配置列表授权的 API token 和范围受限的完整文件读取 API。
- 完整范围与权限、数据、一致性和验收要求见 [v0.1.1 需求](v0.1.1.md)。

Android 同步识别服务端关闭注册的稳定错误，并发布 versionName `0.1.1` 的新安装包。Android 用品/保修提醒按 [到期提醒规格](reminders-spec.md) 留待后续版本规划。

## 后续候选：按反馈决定

复制记录、CSV 导入导出、标签与位置管理、批量归档、出售回收金额和维修记录均未承诺版本。CSV 不替代现有 JSON 完整备份。

用品仍只做期限管理，不增加库存、消耗和补货预测。心愿清单、独立趋势页、新工具类别与 AI/OCR 不在当前交付范围。iOS、数据库替换与 C++ 抽取的决策及重启条件见 [平台与存储评估](../history/platform-and-storage-evaluation.md)。
