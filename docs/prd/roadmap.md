# 版本规划

2026-09-30：先发布 v0.1.0-preview 预发布版，再完成 v0.1.0 正式分发；阶段 A、C 的剩余事项进入下一版本，版本号待定。

## v0.1.0：发布现有能力

范围见 [v0.1.0 需求与边界](v0.1.0.md)。本轮不增加业务功能，完成正式签名、安装验证、隐私与分发准备。

已有实施与测试证据见 [执行记录](../history/roadmap-execution.md)。旧路线图中已经完成的入口修正、统计口径、表单和列表体验工作不再重复排期。

## 下一版本

- 阶段 A：补完后台长期多周期、实体设备低内存回收、Doze 和厂商省电策略验收。已有 AVD、受控恢复与本地模式 Worker 结果只作为已有证据，不替代未完成的实机验收。
- 阶段 C：按 [到期提醒规格](reminders-spec.md)，先更新既有 OpenDesign，再实现用品到期通知、保修提醒与首页待处理入口。提醒默认关闭；不承诺精确到分钟送达。

以上两项不阻塞 v0.1.0，但必须在发布说明中保留能力与验收边界。

## 后续候选：按反馈决定

复制记录、CSV 导入导出、标签与位置管理、批量归档、出售回收金额和维修记录均未承诺版本。CSV 不替代现有 JSON 完整备份。

用品仍只做期限管理，不增加库存、消耗和补货预测。心愿清单、独立趋势页、新工具类别与 AI/OCR 不在当前交付范围。iOS、Web、数据库替换与 C++ 抽取的决策及重启条件见 [平台与存储评估](../history/platform-and-storage-evaluation.md)。
