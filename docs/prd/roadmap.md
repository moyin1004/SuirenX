# 版本规划

2026-10-15：v0.1.2 源码与 Android 签名 APK 已发布，主要修复日常体验与两项服务端边界问题；正式服务部署和剩余交互验收独立追踪。v0.1.1 已于 2026-10-04 发布 Web 管理与 Android 客户端更新。用品/保修提醒及阶段 A 剩余可靠性验收继续延期。设计相关 UI 实施前仍需更新原稿并重新核验连接。

## v0.1.0：已完成正式发布验收

范围与验收要求见 [v0.1.0 需求与边界](v0.1.0.md)。维护者于 2026-10-03 确认正式发布验收完成。

已有实施与测试证据见 [执行记录](../history/roadmap-execution.md)。旧路线图中已经完成的入口修正、统计口径、表单和列表体验工作不再重复排期。

## v0.1.1：Web 平台、管理与 Android 更新

- v0.1.0 正式发布验收已完成；阶段 A 剩余 Android 后台与实体设备可靠性验收延期，不阻塞本版本。
- 新增共享 Android 同步账号数据的响应式 Web 客户端，覆盖资产/用品主要操作；Web 写入经版本化接口进入现有同步事件流，Android 仍以 Room 为本地唯一数据源。
- 新增超管登录及账号状态管理、所有业务数据管理、通用文本配置文件管理、按配置列表授权的 API token 和范围受限的完整文件读取 API。
- 完整范围与权限、数据、一致性和验收要求见 [v0.1.1 需求](v0.1.1.md)。

Android 同步识别服务端关闭注册的稳定错误，并发布 versionName `0.1.1` 的新安装包。Android 用品/保修提醒按 [到期提醒规格](reminders-spec.md) 留待后续版本规划。

## v0.1.2：实际使用中的 bug 与体验修复

2026-10-15：两项发布前 review 问题已修复，维护者授权后已发布 [v0.1.2](https://github.com/moyin1004/SuirenX/releases/tag/v0.1.2)，Android 使用 `versionCode=3` / `versionName=0.1.2`；其余原稿、浏览器与实体设备验收继续追踪，不宣称完成。服务端源码随版本发布，实际部署单独执行。

2026-10-12：维护者确定本版本主要修复实际使用中遇到的 bug 和体验问题。Android 与 Web 的具体问题按反馈逐项记录，实施优先级由复现结果、数据影响和使用阻碍决定。

- 每项反馈记录平台、操作步骤、实际结果和期望行为；先复现和定位，再修复并验收原操作路径。
- UI 或交互调整先更新既有 OpenDesign 原稿，再实现应用；验收包含实际预览或浏览器/设备交互证据。
- 首批 Android 反馈：资产页默认「服役中」，完整/压缩总览随状态、标签和搜索筛选；切页时标签与正文同步并保留页面状态；用品期限日期框与其它字段同宽；退役日期通过日历选择，限定购买日至今天，取消不提交。首页继续汇总全部未归档资产。
- 资产页总览卡片布局：顶部「资产概览」后紧跟「当前标签下数量/总数」（如 `3/5`），取消最右侧筛选徽标；分子随状态、业务标签及搜索变化，分母为包括已归档在内的全部资产数。金额区左侧「总资产金额」、右侧「日均成本」，总资产字号略大；下方浅灰圆角指标条分别为「服役中」「已退役」「最长持有天」，每组文字与数值并排。继续使用当前筛选口径。
- 2026-10-13 追加反馈：「全部」筛选包含已归档资产，归档记录参与此筛选的购入总额、项数与最长持有天汇总；服役中/已退役筛选及日均成本仍排除归档记录，首页仍统计全部未归档资产。归档记录保持只读、恢复后才能编辑。
- 2026-10-13 实体手机反馈：资产页总览金额保持单行，宽度不足时适配字号；资产卡片名称保持单行，超出可用宽度时自动横向滚动，短名称静止，卡片点击仍进入详情查看完整名称。
- 名称使用无额外字距的排版，以实际文字宽度判断是否溢出；能完整放入卡片的中英文混合名称保持静止。
- Android 账号页的密码显示切换使用输入框右侧眼睛图标按钮，移除独立的文字按钮；图标提供「显示密码 / 隐藏密码」可访问说明，提交中保持禁用。
- 注册密码的实际规则：8–72 个可打印 ASCII 字符（英文大小写字母、数字、英文符号、空格），不允许中文、emoji、控制字符；不要求必须混合大小写、数字或符号，空格不自动裁剪。密码框下展示这些要求，删除 UTF-8 字节说明。已有账号登录仍按原密码核验，不因新注册规则失效。
- 既有 Web 表单提交修复及未发布的认证限流、配置上限、审计日志改动保留进度。待办和未验证范围见 [当前待办](../TODO.md)，具体问题列表随维护者反馈补充。

## 后续候选：按反馈决定

复制记录、CSV 导入导出、标签与位置管理、批量归档、出售回收金额和维修记录均未承诺版本。CSV 不替代现有 JSON 完整备份。

用品仍只做期限管理，不增加库存、消耗和补货预测。心愿清单、独立趋势页、新工具类别与 AI/OCR 不在当前交付范围。iOS、数据库替换与 C++ 抽取的决策及重启条件见 [平台与存储评估](../history/platform-and-storage-evaluation.md)。
