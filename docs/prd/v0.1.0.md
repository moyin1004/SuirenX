# v0.1.0 需求与发布边界

状态：维护者于 2026-10-03 确认 `v0.1.0` 正式发布验收已完成。2026-09-30 确认本版以现有 Android 功能为范围。

## 用户能力

- 资产：记录与编辑、搜索筛选与排序、持有天数与日均成本、退役与重新启用、归档恢复和显式删除。
- 用品：期限记录、开封后期限、搜索、状态处理与归档；位置可不填。不包含库存或补货预测。
- 数据：本地 Room 为唯一数据源；离线读写、包含归档记录的 JSON 备份与恢复，恢复前自动备份。
- 可选同步：账号与服务器地址独立，用户明确开启后同步；保留待发送变更，冲突需显式处理。Release 连接服务器需 HTTPS。

## 不包含及已知边界

- 到期通知、保修通知和首页待处理入口留到下一版本，不能在发布文案中描述为已支持。
- 后台长期调度、实体设备低内存回收与 Doze/厂商省电策略的完整验收顺延；不能承诺后台同步实时或持续可靠。用户仍可手动同步。
- 本次发布目标为 Android APK；现有 workflow 不部署 Go 服务，也不生成应用商店用 AAB。
- 签名、备份排除配置和既有自动化测试不能替代正式签名 APK 的设备安装验收。

## 发布验收

预发布版本配置为 `versionName=0.1.0-preview`、`versionCode=1`。正式发布使用唯一递增的 versionCode，tag `v0.1.0` 不复用。

维护者于 2026-10-03 确认 [发布准备](../release-readiness.md) 中的正式签名、安装、隐私与分发验收已完成。阶段 A、C 延期不影响本版验收状态。

预发布 tag 为 `v0.1.0-preview`，GitHub Release 标记为 Pre-release。未配置正式签名时仅提供源码与 unsigned 构建，不能视作可安装的正式 APK。正式分发使用新的唯一 versionCode。
