# 2026-10-03：v0.1.1 Web 与 Android 实施记录

## 设计与技术决策

- OpenDesign 本地项目 `suirenx-asset-ui-redesign` 恢复可读。既有 `suirenx-asset-redesign.html` 已覆盖 Android 原型与新增 Web 流程；原型预览中实测了 Web 演示工作区和资产列表，确认内容实际渲染。此前报告空白来自停留在登录入口且视口滚动位置偏下；进入演示工作区后截图显示正常页面。
- 仓库没有 Web 构建工具链。v0.1.1 前端选择原生 HTML/CSS/JavaScript，以 Go `embed` 随 API 服务同源交付；不新增 Node 依赖、构建系统、CORS 或 Cookie 会话。该方案减少小型单体应用的发布步骤，但页面当前缺少自动化浏览器测试和独立静态资源版本缓存。
- 页面通过 sessionStorage 保存当前标签页 JWT，并以 Bearer header 调用 `/api/v1`；服务端提供安全响应头和 `no-store`。API token 管理仍独立于登录 JWT，token 明文仅在签发响应后的确认视图短暂显示。
